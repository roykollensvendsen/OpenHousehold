# ADR-004 — license original project material under Apache-2.0

Status: Accepted for repository setup, 2026-09-20.
Chosen as a repository default within the requested setup; no claim of an
independent owner preference from the voice conversation.

Decision: use the unmodified Apache License 2.0 for original repository content.
The project aims for reuse across households and integrations. A permissive
license with an express patent grant fits that aim. Alternatives were MIT and
strong copyleft; the draft does not require downstream changes to be published.

The [license text](../LICENSE) controls its terms. This choice grants no rights to
third-party banking data, trademarks, standards or copied software beyond their
own licenses. Review each component before integration; publishing the project
under Apache-2.0 does not relicense Firefly or any other dependency. GitHub
visibility is an independent hosting choice; the user approved public visibility.
